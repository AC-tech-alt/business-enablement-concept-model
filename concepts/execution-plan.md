# Execution Plan

## Definition

The concrete build-out of a [Workflow](./workflow.md): system configuration, training materials, communication plan, sequencing, and named accountable owners for each step.

## Properties

- **Build owner** — typically a technology or operations function
- **Sequencing** — the order steps must happen in
- **Named owners per step** — not just one overall owner for the whole plan

## Relationships

- An Execution Plan belongs to exactly one [Workflow](./workflow.md).
- Completing an Execution Plan produces [Field Readiness](./field-readiness.md) — it does not skip directly to Adoption.

## Rules

- An Execution Plan can be marked complete while the underlying Workflow is still unadopted in the field. Completion of build is not completion of impact — this is the single most important distinction in the whole model.
