# Value Realization

## Definition

The measurable business or operational outcome the [Initiative](./initiative.md) was chartered to produce — for example, reduced turnaround time, an improved outcome metric, or cost avoidance.

## Properties

- **Target metric** — set when the [Business Problem](./business-problem.md) was named
- **Measurement window** — the period over which the outcome is evaluated
- **Actual result**

## Relationships

- Value Realization is evaluated against the target set by the original [Business Problem](./business-problem.md).
- Value Realization can only be meaningfully assessed once [Adoption](./adoption.md) has held for a defined period.

## Rules

- Evaluating Value Realization before Adoption has held is the most common way organizations conflate "we shipped it" with "it worked." A technically successful rollout with no sustained adoption will show no real value, regardless of how well it was built.
