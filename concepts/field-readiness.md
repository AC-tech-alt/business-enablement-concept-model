# Field Readiness

## Definition

The state in which the people expected to run a [Workflow](./workflow.md) have the training, tools, local process support, and communicated rationale to do so.

## Properties

- **Readiness criteria** — the specific checklist that defines "ready" for this workflow
- **Training completion rate**
- **Field feedback status** — open questions or concerns raised by the people who will actually run the workflow

## Relationships

- Field Readiness is produced by a completed [Execution Plan](./execution-plan.md).
- Field Readiness is a precondition for [Adoption](./adoption.md).

## Rules

- Field Readiness is a precondition for Adoption, not a synonym for it. A team can be fully "ready" — trained, equipped, briefed — and still not be using the new workflow a month later.
